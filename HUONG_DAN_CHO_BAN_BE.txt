================================================================================
 HƯỚNG DẪN NẠP CẤU HÌNH NHANH (DÀNH CHO BẠN BÈ / ĐỒNG ĐỘI)
================================================================================

Chào bạn! Đây là gói cấu hình bí mật (API Keys + OAuth Channels) của dự án.
Bạn có thể áp dụng vào máy của mình bằng 1 trong 3 cách cực kỳ đơn giản sau:

--------------------------------------------------------------------------------
👉 CÁCH 1 (NHANH NHẤT NẾU DÙNG TRỢ LÝ ANTIGRAVITY):
--------------------------------------------------------------------------------
1. Bạn copy file 'secrets_config.zip' này vào thư mục dự án của bạn (E:\AI Youtube\AI-youtube-main hoặc thư mục cha E:\AI Youtube).
2. Mở khung chat Antigravity lên và gõ nguyên văn dòng chữ sau:
   "Hãy giải nén và áp dụng cấu hình từ file secrets_config.zip vào dự án giúp tôi"
3. Antigravity sẽ tự động đọc và nạp toàn bộ API Keys (.env: Gemini, Pexels, Pixabay, Hugging Face, Telegram) và các kênh YouTube cho bạn ngay lập tức!

--------------------------------------------------------------------------------
👉 CÁCH 2 (CLICK ĐƠN GIẢN BẰNG TAY):
--------------------------------------------------------------------------------
1. Giải nén toàn bộ file 'secrets_config.zip' thẳng vào thư mục code chính (AI-youtube-main).
2. Nhấn đúp chuột vào file: nhap_cau_hinh.bat
3. Màn hình báo "NẠP CẤU HÌNH THÀNH CÔNG" là xong!

--------------------------------------------------------------------------------
👉 CÁCH 3 (GIẢI NÉN ĐÈ THỦ CÔNG):
--------------------------------------------------------------------------------
Giải nén và kéo thả đè trực tiếp các thư mục/file:
 - .env
 - config/channels.yaml
 - credentials/
vào đúng thư mục dự án của bạn.
================================================================================

--------------------------------------------------------------------------------
🚀 SỬ DỤNG CHUNG COLAB GPU FARM (RENDER 20 GIÂY BẰNG A100/T4):
--------------------------------------------------------------------------------
1. Khi chủ phòng (anh Giang) mở file 'colab_gpu_worker.ipynb' trên Google Colab Pro+ và gửi cho bạn đường link Cloudflare Tunnel (dạng https://...trycloudflare.com).
2. Bạn chỉ cần mở Telegram bot gõ:
   /colab https://...trycloudflare.com
3. Toàn bộ video bạn yêu cầu render sẽ bay sang GPU A100/T4 của Colab để render trong 20s!
4. Nếu chủ phòng tắt Colab, máy bạn vẫn tự động render bình thường bằng CPU (không bao giờ lỗi).
